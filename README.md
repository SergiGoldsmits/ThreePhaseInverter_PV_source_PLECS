# ThreePhaseInverter_PV_source_PLECS
This project simulates a three-phase voltage source inverter (VSI) connected to the grid, implementing current-controlled PWM modulation in both the stationary abc frame and the rotating dq0 frame. A second model extends the system to include a photovoltaic (PV) source on the DC bus with a capacitor filter, modelling a real grid-tied solar inverter
